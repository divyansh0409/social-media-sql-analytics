# social-media-sql-analytics
Instagram Clone Analytics: SQL-Driven Engagement & Marketing Insights

A SQL case study where I act as a data analyst for a social media company’s Marketing team. Using the ig_clone MySQL database (users, photos, likes, comments, follows, tags, photo_tags), I answer 13 objective and 10 subjective business questions to understand user behaviour and suggest strategies to improve engagement, retention and acquisition.

What’s covered

Data quality checks (NULLs, duplicates)
User activity distribution and average engagement per post
Ranking top loyal users by likes + comments
Followers/following analysis and influencer candidates
Hashtag performance and content strategy
User segmentation by content preference
Inactive user identification and re-engagement ideas

Key findings

Data was clean, with no NULL or duplicate records
13 top loyal users identified for loyalty and referral programs
Top-5 influencer / brand-advocate candidates picked using followers + engagement per post
delicious, beauty and foodie hashtags earned the highest engagement per post
26 inactive users segmented into win-back groups

SQL concepts used: JOINs, CTEs, subqueries, aggregations, window functions (RANK, DENSE_RANK, PARTITION BY), COALESCE, date functions

Tools: MySQL, PowerPoint (presentation of insights)
